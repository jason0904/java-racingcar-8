# java-racingcar-precourse

## 기능 구현 목록

### 입력
- [x] ```경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)``` 출력 후 문자열 입력 받기.   
- [x] ```시도할 횟수는 몇 회인가요? ``` 출력 후 정수 양수 숫자 입력받기.   
- [x] 자동차 이름이 겹치면 예외 발생시키기.
- [x] 자동차 이름이 공백이면 예외 발생시키기.
- [ ] 자동차 이름이 6자 이상이면 예외 발생시키기.
- [x] 자동차 이름 입력의 마지막이 쉼표로 끝나면 예외 발생시키기.
- [x] 공백이 들어오면 예외 발생시키기.
- [x] 시도할 횟수가 0이면 예외 발생시키기.
- [x] 시도할 횟수에 실수가 들어오면 예외 발생시키기.
- [x] 시도할 횟수에 음수가 들어오면 예외 발생시키기.
- [x] 시도할 횟수에 숫자가 아닌 문자가 들어오면 예외 발생시키기.


### 출력
- [x] ```실행결과``` 출력 후 각 라운드 별 실행 결과 출력.
- [x] 시도 횟수가 다 끝나면 최종 우승자 출력.   

### 자동차 움직이기
- [ ] 랜덤 번호가 4이상이면, 자동차의 값을 1 상승시킨다.

### 우승자 찾기
- [ ] 값이 가장 큰 자동차를 찾는다.
